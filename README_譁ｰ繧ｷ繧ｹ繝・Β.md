## これは何か（継ぎ足しの根本解決）
現行アプリの「継ぎ足し構造」をやめ、**ゼロから構造を整えた新システム**です。記録・達成率・目標・個人・ホーム・Excel出力まで一通り入っています。最大の特徴は——

- **マスタ（店舗・商材・プラン等）を1か所に集約**（`src/data/masters.js`）。各画面はここだけを読む。商材を足す/直すときも原則ここ1か所。**ベタ書きの分散＝継ぎ足しを断つ**。
- 達成率の計算は専用ロジック（`src/lib/aggregate.js`、**テスト済み**）に集約。
- **データは現行(plus-manager-58162)と同じ**を読み書きします。だから移行（データ引っ越し）が不要——記録の保存先が同じ`reports`なので、「記録UIを新しい方に切り替えるだけ」で乗り換えられます。

## LINE通知の文面（確定仕様）
- **1台＝1通**。縦書き・前置きあり。各行を**略称で短く**して、単語の途中改行を防止。
- 例:
```
お疲れ様です。
獲得報告です。

[09:49] 竹内由
種別：MNP
契約：dcm→aHM
店舗：中道
機種：iP17Pro
色容量：黒 256GB
プラン：MAX+
保証：故紛
LTV：Netflix
+1c：¥15,000 Norton4年
CB：¥30,000
申:A-1234
ARCH:A998877665
```
- **回線(au/UQ)** は契約のすぐ後に `（au）`/`（UQ）`（でんき・PAYカード・ゴールド・じぶん銀行・Pontaのとき）。
- **申込書番号・ARCH番号は略さず全桁**（各1行）。IMEI/ICCIDも入力時のみ各1行。
- 修正時は先頭に「📝【修正】再入力報告です。」。削除時は別途「🗑削除 …」を通知。
